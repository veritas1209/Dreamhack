플래그를 복호화 시 "?->?" 라는 부분이 있습니다. 이곳에 틀린 코드를 올바르게 고쳐 넣어주세요. 예) 틀린 코드:A 올바른 코드:B "?->?" -> "A->B" 

During flag decryption, you will see a section formatted as "?->?". Replace this with the correction in the format "incorrect_chord->correct_chord". Example: Incorrect chord: A, Correct chord: B → "?->?" should be written as "A->B".
